# Smile Assistant

عايز اعمل موقع كامل لعيادة طبيب اسنان طلها باللغة العربية يكون في قائمة بالجانب للتسهيل على الطبيب الموقع يعمل كمساعد لمتابعة المواعيد و ملفات المرضى بحيث يتم فتح ملف للمريض و بالاسم و رقم الهاتف و عايز اعمل قائمة الخدمات ة هي (تنظيف الاسنان – حشو الاسنان – كشف عام )

اريد عمل قئمة بالمواعيد التي سبق وتم حجزها العيادة تفتح من الساعة 9 صباحا حتى 2 مساءا و قل هذا كملاحظة ولا تضع اي مواعيد في عكس هذه المدة عايز الموقع يكون سلس و بسيط
